One line, written for a one-line comedy bounty: a phone placed on
airplane mode that commits to the bit completely. It refuses to land
until its owner watches the safety video, and the safety video is a
review of the owner's own life choices. Tray tables up.

## Running it

`node main.ts` clears the output directory's contents and writes the
line to `/output/entry.txt` as plain UTF-8 text.
